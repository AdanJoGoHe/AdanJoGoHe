## Selected work

### 🛠️ [OldSolutions — Repair shop management](https://github.com/AdanJoGoHe/XamarinProject)

A documented prototype for managing repairs in a computer shop. It covers the project from user stories and data modelling to application flows and a visual user guide.

`C#` · `Xamarin.Forms` · `Node.js` · `MySQL` · `SQLite`

- Designed the repair lifecycle, including creation, postponement, completion and delivery.
- Documented the relational model, use cases, class structure and technology choices.
- Built mobile CRUD flows for customers, operators, products and repairs.
